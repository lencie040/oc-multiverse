# オリキャラ多元宇宙

オリキャラ一覧（Google スプレッドシート）をもとに、全キャラクターが自分で暮らす様子を 3D で眺めるアプリです。

## 見かた

- **宇宙** … 世界団ごとの球体。クリックするとその世界団へ。
- **世界団** … 世界線の球体。汎異記号の1文字目（英字）が同じ世界線は近くに集まり、線でつながっているのが「隣の世界線」。赤い輪は魔物の多さ。
- **世界線** … 浮島の上で住人が暮らしています。地面の色は世界線ごとに違い、構造物・自然物は世界線名や住人から雰囲気を想像して置いています。端の光る輪は隣の世界線へのポータル（クリックで移動）。

| 操作 | |
|---|---|
| W A S D | 移動 |
| Q / E | 回転 |
| ホイール, R / F | 拡大・縮小 |
| ドラッグ | 視点 |
| クリック | 選択・移動 |
| T | 選択中のキャラを追跡 |
| O | おまかせ観戦 |
| M | 音のオン・オフ |
| H | パネルの表示切替 |

| / | 検索（世界線名・読み・汎異記号・キャラ名） |
| Esc | 選択解除 / 1つ上の画面へ |

## 眺めて楽しむ機能

- **🎬 おまかせ観戦**: レイド・世界団越え・伝説の宝物・親友誕生など、見どころのある出来事にカメラが自動で向かいます。何もない時はレイド中の世界線や旅人を映します。カメラの距離・角度・回り込みは場面（会話のアップ、戦闘、レイドの全景、移動中など）に合わせて自動で調整され、マウスで動かすと6秒ほど手動になります（WASD・Esc で終了）。
- **実況テロップ**: 大きな出来事が画面上部に流れます（クリックでその場所へ）。
- **📰 日報**: 毎朝6時に前の日の出来事（魔物退治MVP・レイド・新しい親友・宝物・世界団越え）が新聞になります。
- **友好度**: おしゃべり・遊びに行く・手伝い・一緒の冒険やレイドで仲良くなり「友達」「親友」になります。野宿を断ったり撃退したりすると「ライバル」に。仲のいい相手ほどよく会いに行きます。
- **ランキング**: 魔物退治・世界線移動・宝物・レイド勝利・友達の数（宇宙の画面の右パネル）。
- **リアクション**: 行動に合わせて頭上に絵文字が浮かび、戦闘中はダメージの数字が飛びます。

## 音

BGM と効果音は音声ファイルを使わず、ブラウザの Web Audio API でその場で作曲・合成しています（最初にどこかをクリックすると鳴り始めます）。

- **BGM**: 宇宙・世界団の画面は「星の海」。世界線では雰囲気に合わせた曲調（のどかな日常／あまいメロディ／森のささやき／波と太陽／闇のささやき／ハロウィンの夜／灼熱の大地／凍てつく結晶／電子の街／祈りの光／古の砂／リズムの国）で、メロディは世界線ごとに違います。夜はゆったり、レイド中は「レイドバトル！」に切り替わります。
- **効果音**: クリック、画面切り替え、ポータル移動、世界団越え、戦闘のヒット、レイド出現の警報、勝利のファンファーレ、敗北、宝物、親友誕生、日報、おしゃべりなど。
- 右下で BGM・効果音の音量を調整できます（設定はブラウザに保存）。タブが隠れている間や最小化中は音が止まります。

## ルール

- 1日 = 現実の20分（右上で ×5〜×120 に早送りできます）。全キャラ Lv50。
- 行動は「デイリー」「趣味」「仕事」「戦闘」「移動」「サボり」「交流」「修行」「買い物」「探検」「手伝い」「レイド」。サボりは家にいる時だけ。
  - 交流: おしゃべり、ほかの住人の家に遊びに行く
  - 修行: その日の戦闘力が1割上がる
  - 買い物: お店で買い物（旅先ではお土産）
  - 探検: 世界線の奥地を探索。まれに宝物、ごくまれに伝説級の宝物を見つける
  - 手伝い: 仕事中の住人を手伝う
- 汎異記号の数字が大きい世界線ほど魔物が多く強い（数字は40で頭打ち。80や99の世界線も40と同じ扱い）。戦闘は戦闘力勝負（Lv50 の実数値合計 × ランク補正）。
- ランク9以上は1日3回まで隣の世界線へ移動可能。日帰りも、帰らずに遠出もします。遠出した夜はその世界線の住人に野宿の許可をもらい、断られたら残りの移動回数で別の世界線へ、回数がなければ断った住人を撃退して野宿します。
- 魔物や住人に負けると次の日の朝までその場で倒れます。
- **レイド**: 汎異記号の数字が20以上の世界線に、昼の間まれにレイドボスが現れます。一人では勝てない強さなので、その世界線にいるキャラ全員と、隣の世界線にいるランク9以上（と仲間）が救援に集まり、90分後に全員で戦います。負けると参加者は朝まで倒れますが、勝っても負けてもボスは消滅します。
- ランク10以上は「ランク − 9」人まで、同じ汎異記号の仲間を連れていけます。
- ランク11以上は3日に1回だけ世界団を越えられ、その日は力が半減します。
- 移動は瞬間移動ではなく、世界線の移動は世界団マップ上の線に沿って（20分前後）、世界団の移動は宇宙マップ上を（約1.5〜2時間）実際に飛んでいきます。移動中のキャラを追跡（T）すると、カメラがマップ上で追いかけ、到着するとその世界線に切り替わります（追跡中の移動は見逃さないよう最大×5に自動で落ちます）。世界線の画面でも、出発するキャラはポータルから空へ飛び立ち、到着するキャラは空から降りてきます。
- 所属は汎異記号を優先。MG・CC・覚醒・EV と、種族値が未入力のキャラはまだ登場しません。
- 状態はブラウザに自動保存され、次に開いたときに続きから始まります。

## データの更新

スプレッドシートを更新したら、イラストフォルダを指定して再生成します。

```bash
python3 tools/build_data.py "/path/to/illust"
```

`data/data.json` と `img/` が作り直されます。

コードを変えて公開するときは、ブラウザのキャッシュ対策に `python3 tools/bump_version.py <番号>` で読み込み番号を上げてください。

## ローカルで動かす

```bash
node tools/serve.mjs
```

http://localhost:8765/ を開きます（`file://` では動きません）。
