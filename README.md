# オリキャラ多元宇宙

オリキャラ一覧（Google スプレッドシート）をもとに、全キャラクターが自分で暮らす様子を 3D で眺めるアプリです。

## 見かた

- **宇宙** … 世界団ごとの球体。クリックするとその世界団へ。
- **世界団** … 世界線の球体。汎異記号の1文字目（英字）が同じ世界線は近くに集まり、線でつながっているのが「隣の世界線」。赤い輪は魔物の多さ。
- **世界線** … 浮島の上で住人が暮らしています。地面の色は世界線ごとに違い、構造物・自然物は世界線名や住人から雰囲気を想像して置いています。端の光る輪は隣の世界線へのポータル（クリックで移動）。

| 操作 | |

| Q / E | 回転 |
| ホイール, R / F | 拡大・縮小 |

## 臨時イベント

- **🐉 レイド**: 上記の通り。
- **🛡️ 魔物の大群（防衛戦）**: 昼の間まれに、魔物のいる世界線へ弱い魔物の大群が3つの波で押し寄せ、町（広場）を目指して進んできます。その世界線にいる全員が迎え撃ち、広場までたどり着いた魔物の数だけ町の耐久が減ります。全滅させれば防衛成功（守った仲間同士が仲良くなる）、耐久が0になると町が荒らされ、しばらく住人が片付けをします。
- **🗺️ 宝の地図争奪戦**: 探検中にまれに宝の地図が見つかり、伝説の宝をめぐる争奪戦が始まります。ランク9以上が見つけた場合は同じ世界団の1〜3つ先の世界線、それ以外はその世界線に宝が眠っています。近くのランク9以上や地元のキャラもうわさを聞きつけて参戦し、現地で掘り当てた人の勝ち（地図を持っている本人は当たりやすい）。

## キャラらしさ（シートのデータから）

- **🎂 誕生日**: シートの誕生日にあわせてカレンダーが進みます（初めて開いた日が0日目の日付。時計に今日の日付が出ます）。誕生日の朝にお知らせが出て、夕方（15時〜）に誕生日パーティーが開かれます。仲のいい順に住人が集まり（友達・親友はほぼ来る、同じ勢力・同じ族も来やすい）、隣の世界線の友達も移動ptがあれば駆けつけます。終わると主役と参加者が仲良くなり、プレゼントがもらえます。同じ日・同じ世界線に誕生日の人が複数いると合同パーティーに。宇宙の画面の「誕生日カレンダー」で1週間先まで確認できます。
- **🚩 勢力**: 勢力（3人以上）は、いちばん多くのメンバーが住む世界線を本拠地にして、ときどき催しを開きます。海軍・軍・隊は「合同訓練」（参加者はその日の戦闘力1割増し）、SHOP・製は「商談会」、それ以外は「集会」。同じ本拠地の勢力どうしは「勢力対抗戦」（綱引き・リレー・腕相撲・料理対決など）で競います。各勢力の上位5人が出場し、種族値（綱引きならHとA、リレーならS など）と運で勝負。見物人も集まります。
- **⚔️ タイプ相性**: 魔物・大群・レイドボスにもタイプがあり（世界線の雰囲気で決まる）、相性がいいと戦闘力が上がり、悪いと下がります（最大およそ1.5倍〜0.65倍）。キャラは相性のいい魔物を選んで戦います。相性表はスプレッドシートの「タイプ相性」シート（行=攻撃側、列=防御側）から `tools/build_data.py` で読み込みます。攻撃側は一番効くタイプで攻め、防御側の複合タイプは掛け合わせ、それを穏やかにした倍率を戦闘力にかけます（無効は1/4扱い）。キャラ詳細に「有利／苦手」なタイプが出ます。

## 眺めて楽しむ機能

- **🎬 おまかせ観戦**: レイド・世界団越え・伝説の宝物・親友誕生など、見どころのある出来事にカメラが自動で向かいます。何もない時はレイド中の世界線や旅人を映します。カメラの距離・角度・回り込みは場面（会話のアップ、戦闘、レイドの全景、移動中など）に合わせて自動で調整され、マウスで動かすと6秒ほど手動になります（WASD・Esc で終了）。
- **実況テロップ**: 大きな出来事が画面上部に流れます（クリックでその場所へ）。
- **📰 日報**: 毎朝6時に前の日の出来事（魔物退治MVP・レイド・誕生日・勢力対抗戦・新しい親友・宝物・世界団越え）が新聞になります。
- **友好度**: おしゃべり・遊びに行く・手伝い・一緒の冒険やレイドで仲良くなり「友達」「親友」になります。野宿を断ったり撃退したりすると「ライバル」に。仲のいい相手ほどよく会いに行きます。
- **ランキング**: 魔物退治・世界線移動・宝物・レイド勝利・友達の数・対抗戦の勝利（宇宙の画面の右パネル）。
- **リアクション**: 行動に合わせて頭上に絵文字が浮かび、戦闘中はダメージの数字が飛びます。

## 音

BGM と効果音は音声ファイルを使わず、ブラウザの Web Audio API でその場で作曲・合成しています（最初にどこかをクリックすると鳴り始めます）。

- **BGM**: 宇宙・世界団の画面は「星の海」。世界線では雰囲気に合わせた曲調（のどかな日常／あまいメロディ／森のささやき／波と太陽／闇のささやき／ハロウィンの夜／灼熱の大地／凍てつく結晶／電子の街／祈りの光／古の砂／リズムの国）で、メロディは世界線ごとに違います。夜はゆったり、レイド中は「レイドバトル！」に切り替わります。
- **効果音**: クリック、画面切り替え、ポータル移動、世界団越え、戦闘のヒット、レイド出現の警報、勝利のファンファーレ、敗北、宝物、親友誕生、日報、おしゃべりなど。
- 右下で BGM・効果音の音量を調整できます（設定はブラウザに保存）。タブが隠れている間や最小化中は音が止まります。

## ルール

- 時間は現実の時計と同じ（端末の日付・時刻）。誰もブラウザを開いていない間の出来事は、次に開いたときに最大2日分さかのぼって一気に進みます（それより前は飛ばします）。タブを隠している間の遅れも、戻ったときに追いつきます。全キャラ Lv50。
- 行動は「デイリー」「趣味」「仕事」「戦闘」「移動」「サボり」「交流」「修行」「買い物」「探検」「手伝い」「レイド」「催し」（誕生日パーティー・勢力の集会・対抗戦）。サボりは家にいる時だけ。
  - 交流: おしゃべり、ほかの住人の家に遊びに行く
  - 修行: その日の戦闘力が1割上がる
  - 買い物: お店で買い物（旅先ではお土産）
  - 探検: 世界線の奥地を探索。まれに宝物、ごくまれに伝説級の宝物を見つける
  - 手伝い: 仕事中の住人を手伝う
- 汎異記号の数字が大きい世界線ほど魔物が多く強い（数字は40で頭打ち。80や99の世界線も40と同じ扱い）。戦闘は戦闘力勝負（Lv50 の実数値合計 × ランク補正 × タイプ相性）。
- 世界線の移動には**移動pt**を使います。隣の世界線へ、汎異記号の1文字目が同じなら1pt・違えば5pt、世界団の移動は40pt。仲間を連れていくと人数分（2人なら2倍）かかります。
- ptがたまる量: ランク7=2日で1pt、ランク8=1日3pt、ランク9=1日7pt、ランク10=1日15pt、ランク11=1日40pt（毎朝6時に加算、3日分までためられる）。ランク6以下は自分ではptがたまらず、仲間として連れていってもらう時だけ移動します。
- 日帰りも、帰らずに遠出もします（日帰りは往復できるptがある時だけ。帰る時はいちばん安いルートを選ぶ）。遠出した夜はその世界線の住人に野宿の許可をもらい、断られたら残りのptで別の世界線へ、ptが足りなければ断った住人を撃退して野宿します。
- 魔物や住人に負けると次の日の朝までその場で倒れます。
- **レイド**: 汎異記号の数字が20以上の世界線に、昼の間まれにレイドボスが現れます。一人では勝てない強さなので、その世界線にいるキャラ全員と、隣の世界線にいるランク9以上（と仲間）が救援に集まり、90分後に全員で戦います。開戦の時点で集まった戦力がボスの半分に満たなければ撤退し（4分の3未満なら多くの場合は撤退）、倒れる人は出ません。戦って負けると参加者は朝まで倒れますが、勝っても負けても撤退してもボスは消滅します。
- 仲間は同じ汎異記号のキャラで、ptに余裕がある分だけ（最大3人）連れていきます。
- 世界団を越えられるのはランク11以上（40pt × 人数）で、その日は力が半減します。
- 移動は瞬間移動ではなく、世界線の移動は世界団マップ上の線に沿って（20分前後）、世界団の移動は宇宙マップ上を（約1.5〜2時間）実際に飛んでいきます。移動中のキャラを追跡（T）すると、カメラがマップ上で追いかけ、到着するとその世界線に切り替わります（追跡中は「出発の世界線で飛び立つ → マップ上を飛ぶ → 到着の世界線に降りる」の3場面で映します）。世界線の画面でも、出発するキャラはポータルから空へ飛び立ち、到着するキャラは空から降りてきます。
- 所属は汎異記号を優先。MG・CC・覚醒・EV と、種族値が未入力のキャラはまだ登場しません。
- 状態はブラウザに自動保存され、次に開いたときに続きから始まります。

## データの更新

スプレッドシートを更新したら、イラストフォルダを指定して再生成します。

```bash
python3 tools/build_data.py "/path/to/illust"
```

`data/data.json` と `img/` が作り直されます。

コードを変えて公開するときは、ブラウザのキャッシュ対策に `python3 tools/bump_version.py <番号>` で読み込み番号を上げてください。

## ローカルで動かす

```bash
node tools/serve.mjs
```

http://localhost:8765/ を開きます（`file://` では動きません）。
